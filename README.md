# TinDog

TinDog is a responsive landing page for a fictional dating app for dogs. This mini project was created as part of **The Complete Full-Stack Web Development Bootcamp** and gave me practice building a polished page layout with Bootstrap and custom CSS.

## Features

- Responsive navigation bar
- Hero section with animated gradient background
- Feature highlights
- Testimonial and partner logos
- Pricing cards
- Footer with navigation links
- Custom styling for the gradient, icons, profile image, and navigation hover states

## Built with

- HTML5
- CSS3
- [Bootstrap 5](https://getbootstrap.com/) via CDN

## Getting started

1. Clone or download this repository.
2. Open `index.html` in your browser.

No build tools or installation are required. Bootstrap is loaded from a CDN, so an internet connection is needed for its styles.

## Project structure

```text
TinDog/
├── index.html
├── css/
│   └── style.css
└── images/
    ├── iphone.png
    ├── dog-img.jpg
    └── ...
```

Keep the CSS and image paths in this structure, or update the references in `index.html` to match your folders.

## Learning note

This project is a front-end practice project based on material from **The Complete Full-Stack Web Development Bootcamp**. The page is a static landing-page concept; its navigation, download, and signup buttons are visual elements and are not connected to an app or backend.
